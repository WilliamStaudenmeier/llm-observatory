# LLM Dashboard

LLM Dashboard is an interactive LLM evaluation and observability simulator. It presents model comparison, evaluator scores, production traces, span timelines, latency, quality, and cost in a responsive operations console.

The interface uses deterministic sample data and local state, so it runs without API keys or a backend.

## Run locally

```bash
npm install
npm run dev
```

## Validate

```bash
npm run build
npm run lint
```

Built with React, TypeScript, Vite, Radix UI, and Lucide React.
